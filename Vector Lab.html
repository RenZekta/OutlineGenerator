Self-contained browser utilities

Outline Tracer

Convert raster images to clean SVG outlines. Uses marching squares and automatic background detection to generate precise vector paths.

Vector Simplifier

Optimize SVG paths with curve-aware simplification. Reduces point count while preserving geometry using Visvalingam-Whyatt and recursive curve fitting.

Image Tracer

Convert full images to SVG vectors. Features edge detection, colorful region mapping, and blueprint centerline extraction.

PDF Vector Extractor

Extract native vector paths from PDF files. Convert embedded lines and curves directly to SVG format without rasterization.
